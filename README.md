# Connect – Kehlnaht

Dieses öffentliche Repository enthält ausschließlich den automatisch erzeugten GitHub-Pages-Webstand der Connect-Fachanwendung zur Bewertung von Kehlnähten nach DIN EN ISO 5817.

Der spätere Zugriff auf die veröffentlichte Anwendung wird über Cloudflare Access geschützt. Die maßgebenden Quellen, Regeln, Tests und Build-Skripte liegen im privaten Repository `AndreasHardt/connect.hardt-wiehl`. Funktionale Änderungen werden nicht direkt in diesem Repository gepflegt.
